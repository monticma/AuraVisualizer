## Find Dependency Paths

Discover how two files are connected through the dependency chain.

**How to use:**
1. Click the **Path** button in the toolbar
2. Click the **source** file (first node)
3. Click the **destination** file (second node)
4. The shortest path lights up with animated particles

This is useful for understanding:
- How a change in file A could affect file B
- Which files are the critical connectors in your codebase
- Circular dependency chains

Click **Path** again to exit path mode.
